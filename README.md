# smart-subject-tutor
 # 🎓 Smart Subject Tutor (v1.0)

An open-source, zero-API-key Retrieval-Augmented Generation (RAG) tutor built using Python and Streamlit.

## 🚀 Features
- AI-powered subject question answering.
- Retrieval-Augmented Generation (RAG).
- Four adaptive teaching styles:
  - ELI10 – Real-world analogies
  - Exam Topper – Structured exam answers
  - Socratic Professor – Interactive learning
  - Practical Engineer – Application-based explanations
- Knowledge retrieval from custom subject notes.
- Open-source language model support.

## 🛠️ Technology Stack
- Python
- Streamlit
- ChromaDB
- Sentence Transformers
- PyTorch
- Open-source LLM

## 📂 Project Structure
- `app.py` – Main application
- `rag_engine.py` – RAG processing engine
- `data/subject_notes.md` – Subject knowledge base
- `requirements.txt` – Dependencies

## ▶️ How to Run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## 🎯 Objective
To make learning easier through personalized explanations, contextual knowledge retrieval, and adaptive teaching styles.
